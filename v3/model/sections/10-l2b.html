L2b Policy/gate context contribution

L2 enforces a rule — an early CONVERGED is rejected. L2b communicates it: the kernel renders a deterministic, actor-facing context_block into the dispatched packet, so the reviewer is told the rule before it acts and never burns a round on an emit that would be blocked. This is the first ContextAssembly slice — and where L0c’s prompt_concern_refs finally resolve.

One render mechanism, two sources. A template-level context_blocks catalog (id → { body }) is the single body source; role/step prompt_concern_refs (from L0c) and gate/policy context_block_refs are just id lists into it. The kernel resolves the issued refs, orders and dedups them, and renders them into ContextPacket.context_blocks with provenance. Nothing here changes a verdict: blocks are communication only — deleting one cannot change what L2 enforces.

Runtime A concrete trace

The reviewer is dispatched at review; the converge transition carries a round-threshold gate (round ≥ 2) and a context block that states the rule:

1
kernel dispatches the reviewer at review (round 1)
assemble_context_blocks renders two blocks into the packet: reviewer-severity-ontology (provenance source: step_config) and no-converged-before-round-2 (provenance source: gate_binding(review, CONVERGED)) — the latter because CONVERGED ∈ available_ops ∩ L1 capability for the reviewer here
2
the reviewer reads the packet and, at round 1, emits PASS (not CONVERGED)
it was told “no CONVERGED before round 2,” so it does not spend an emit on a doomed converge — contrast L2, where an uninformed reviewer emitted CONVERGED at round 1 and got gate_blocked(round_below_min). Same enforcement; L2b removed the wasted attempt
3
a round later the implementer is dispatched at implement
available_ops ∩ L1 capability = { PASS }; the converge gate is bound to review/CONVERGED, not an op this actor may emit, so no-converged-before-round-2 is not rendered — the reviewer-only rule does not leak into the implementer’s packet
The block is communication, not control: if the reviewer ignored it and emitted CONVERGED at round 1, the L2 gate would still reject it (round_below_min, round not burned). Deleting no-converged-before-round-2 from the catalog changes what the actor is told, never what the kernel enforces.

Pseudocode The rule behind the trace

Two helpers are added — assemble_context_blocks (dispatch-time render) and validate_context_refs (definition-load check) — and the packet gains one field. The kernel handlers are otherwise unchanged:

assemble_context_blocks is deterministic: bodies come only from the catalog, the source order is the render order (role → step → gate), and a repeated id renders once while provenance.sources[] accumulates every emitter. The gate branch reuses the same transition-existence + L1 capability logic the kernel already defines — no fresh authority logic. None of this touches HANDLE’s verdict path.

This table is the contract; assemble_context_blocks is its executable sketch, validate_context_refs enforces the catalog rows at definition load, and the config below is one instance of it.
The boundary with L2 is enforcement vs communication. L2’s gate keeps the system correct; L2b’s block makes the same rule legible from configuration — paying off v1, which baked these operating rules into prompt prose. L2b proves a ref resolves, not that its prose matches the gate it describes (see Absent).

Config The template — a catalog, and the converge gate communicates its rule

The pre-existing reviewer-severity-ontology ref (declared at L0c) now resolves against a new context_blocks catalog, and the L2 converge threshold gate gains a context_block_refs that states the rule it enforces:

The gate still enforces round ≥ 2; the block just says so in words. They are authored separately on purpose at L2b — which is exactly why semantic parity is not guaranteed: bump the gate to value: 3 and the prose would silently lie until someone edits it. Closing that gap needs computed bodies → later.

  • Scenario coverage: the rule renders for the actor who could emit the gated transition, is absent for one who could not, and is deduped to a single block with multi-source provenance.
  • Accepted tradeoff: bodies are authored static text — L2b validates ref existence, not prose-vs-config parity; a gate-value change can leave stale prose until computed bodies land.
  • Invariant coverage: communication-only (L2 enforcement unchanged) ✓; deterministic ordered render ✓; refs validated at create ✓; all L0a–L2a invariants still hold.
  • Known gaps (intended): computed/templated bodies, semantic parity, rich context assembly, actor-adapter rendering. Each is in Absent.
  • Decision: accepted as the L2b baseline (light evidence per playbook §2.1).
